# Dev_comment EN
DR2C Developer Comments

This repository contains all developer comments extracted from the latest public Steam version.
Date of extraction: November 17, 2026. If I have time later, I will run a new extraction and publish a release with the updated date and game version.

**NOTE:** This repo includes both the extraction script and the extracted comments themselves. Keep in mind that the comments may be outdated if you are running a different version of the game (the comments are saved in HTML format).

**Features:** You can jump directly to a specific comment by clicking the link next to it—this will open the corresponding file and line in your default text editor (e.g., VS Code).
